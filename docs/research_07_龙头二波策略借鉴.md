## 1. longtou.py 策略拆解

### 1.1 整体架构

一个**日频状态机 + 六道门 + 影子总分 + 物理隔离未来标签**的研究框架：

```
全A（剔ST/退） → 第一波辨识度发现（top20候选/日）
    → 六道门评估（通过/条件/阻断/数据不足）
    → 九态状态机（合法迁移表 + 跳跃拦截）
    → 影子总分排序（门分加权）
    → 稳定题材锚 / 战术共振 / 定价权影子上下文
    → future_label 独立后验（T+1/3/5/10日，不回写T日）
```

### 1.2 候选发现（第一波辨识度）

- 入池：20日最大阶段涨幅≥35% 或 20日滚动涨停数≥3 或 最大连板≥3；
- 流动性：5日均额≥5000万；上市≥60日；
- 辨识度分 = 40×涨幅项 + 30×涨停数项 + 20×连板项 + 10×成交额分位。

### 1.3 六道门（核心思想：**阻断不可被总分抵消**）

| 门 | 通过条件（摘） | 阻断条件（摘） |
|---|---|---|
| 第一波辨识度 | 涨幅≥60%且涨停≥4，或分≥72 | 涨幅/涨停/连板全弱 |
| 题材生命力 | 板块结构分≥72 且 广度≥55% 且 带动≥0.30 | 板块退潮（广度<25%）或结构分<35 |
| 死亡测试 | 压力区修复≥20% 或 收盘位置≥0.5 | 连续2日≤-5%负反馈，或峰值回撤≤-35% |
| 筹码重组 | 收盘位置≥0.55 且 量比∈[0.55,2.2] 且 修复≥20% | 爆量(≥2.5)低收(<0.3)且未修复 |
| 市场环境 | 主升 且 周期分≥60 且 跌停≤5 且 成交环比≥0.85 | 退潮 / 周期<35 / 跌停≥max(10,涨停×0.5) / 环比<0.6 |
| 龙头稀缺性 | 排名前3 且 未被替代 | 被新核心替代且落后≥8分 |

合成规则：任一阻断→不适用；任一数据不足→数据不足；任一条件→条件观察；全通过→适用。
**影子总分（0.20/0.20/0.20/0.15/0.15/0.10 加权）只用于排序，不能越过阻断与状态机。**

### 1.4 关键机制亮点

1. **死亡测试与炸板识别（broken_board）**：第一波峰值后，出现「触板未封 + 量比≥1.5 + 收盘位置<0.55」即记为死亡测试事件；且**一旦触发，后续创新高不能抹掉**（不可逆记忆）。
2. **收盘位置 close_position = (close-low)/(high-low)**：贯穿死亡测试、筹码重组、T+1承接三处，是统一的K线质量度量。
3. **量比甜蜜区**：筹码重组门偏好 amount_ratio5 ∈ [0.55, 2.2]（温和放量），≥2.5 且低收视为出货阻断——「爆量低收」是明确的负信号。
4. **市场周期分**：cycle = 45×上涨家数占比 + 25×涨停数/80 + 15×(1-跌停/20) + 15×成交环比/1.1，切四档（主升/修复/强分歧/退潮）；**跌停数与涨停数的比例**（跌停≥涨停×0.5 即阻断）是高位反馈恶化的探针。
5. **稳定题材锚 vs 战术共振分离**：锚=申万行业优先、概念需连续2日领先≥5分才切换（切换率审计≤35%）；战术=当日最强标签。二者分离时显式标注「同向/分离」。
6. **定价权/龙头替代追踪**：同一上下文内用辨识度分排名，leader 易主且落后≥8分→「新核心替代」阻断旧龙。
7. **连续负反馈**：峰值后从最近一日倒查，连续≤-5%的天数≥2 即阻断。
8. **工程纪律**：T日状态函数禁止携带 `future_*` 字段（运行时断言）；未来标签在全部T日终检后才采集；停牌/无成交/数据不完整三类分开审计；状态迁移表+守卫拦截跳跃；覆盖率守恒检查。

### 1.5 未来标签体系（后验口径）

- T+1 可交易状态：ready / paused / no_trade / limit_up_locked（一字买不进）/ limit_down_locked；
- T+1 承接标签：accepted（收涨，或 -2%以内且收盘位置≥0.65）/ neutral / negative_feedback（≤-5% 或收跌且位置≤0.25）；
- 1/3/5/10日收益、10日最大涨幅/最大回撤、信号后是否突破压力峰。

## 2. 与我们抓涨停板链路的对照

| longtou 机制 | 我们现状 | 差距/机会 |
|---|---|---|
| 市场环境门（涨跌停比、上涨家数、成交环比） | research/20 已测 idx_prev/idx_open/zt_prev 三闸门 | **跌停家数、涨跌停比、上涨家数占比、市场周期分未测** |
| 题材生命力门（板块广度/涨停密度/带动度） | core/heat.py 题材热度 v2（竞价/盘中实时） | 热度已用于宇宙筛选，但**未作为决策时刻因子**进入封板率模型 |
| 筹码重组门（量比甜蜜区、收盘位置） | 17_enriched 已有 y_cpos/y_vr 昨相字段 | **量比甜蜜区（非线性）与爆量低收组合未单独验证** |
| 死亡测试/炸板疤痕（触板未封，不可逆） | 无 | **全新因子：近20日炸板次数（日线可代理）** |
| 龙头稀缺性/定价权（板块内排名、leader gap） | 打板评分含题材热度项，无板块内相对地位 | **全新因子：行业内当日涨幅排名/与第一名差距** |
| 连续负反馈/压力修复 | 低拉队列有形态因子 | 对首板打板意义有限，更适合二波/低吸，暂缓 |
| 未来标签物理隔离、迁移守卫 | research 系列已遵守前向验证 | 方法论一致，直接沿用 |

**核心启示**：longtou 是「选谁值得做」（质量闸门），我们是「何时能封住」（概率捕捉）。
可迁移的不是它的状态机，而是三类**环境/结构/疤痕**信息：
① 市场当日生态（跌停数、涨跌停比）决定打板总闸门；
② 个股在板块内的相对地位（定价权）决定封板资金是否聚焦；
③ 历史炸板疤痕与爆量低收反映筹码质量，决定次日承接。

## 3. 可开发因子假设（待 research/22 前向验证）

评估口径：封板率（决策时刻→收盘封死，y）、当日胜率（打板入场→收盘）、
次日胜率（next_ret>0）、盈亏比（次日均值口径+中位数口径）、
Forward Return 五档单调性；全部按 train/test 前向切分 × 偏多/震荡/偏空三段行情复核。

### H1 市场生态闸门（跌停家数 / 涨跌停比）
- **假设**：昨日（决策前可见）跌停家数高、跌停/涨停比高 → 今日打板封板率与次日胜率显著下降；longtou 的「跌停≥max(10,涨停×0.5)阻断」在打板场景同样成立。
- **多角度论证**：
  - 机制：跌停家数是高位股亏钱效应的直接度量，炸板/大面次日抑制接力资金；
  - 反方：跌停多可能已是情绪冰点，存在「冰点反转」效应 → 需分档看单调性而非线性；
  - 对照：research/20 已证 zt_prev≤30 有效，本假设检验其互补增量。
- **因子**：`ld_prev`（昨日跌停家数）、`ldlr_prev`（昨日跌停/涨停比）、`adv_prev`（昨日上涨家数占比）、`cycle_prev`（longtou 市场周期分复刻）。

### H2 板块共振广度（决策前一日行业广度）
- **假设**：昨日所在行业上涨广度/涨停密度高 → 今日该股封板率与次日胜率更高（题材生命周期「主升」段打板优于「退潮」段）。
- **多角度论证**：
  - 机制：广度代表板块赚钱效应扩散，跟风资金充裕，封板后次日有接力；
  - 反方：广度过高可能是高潮日，次日面临分歧 → 需检验是否存在倒U（分档单调性）；
  - 数据：daily_panel 全市场可精确计算行业广度（申万行业用 events.industry 近似）。
- **因子**：`ind_breadth_prev`（昨日行业上涨家数占比）、`ind_ztdens_prev`（昨日行业涨停密度）、`ind_score_prev`（longtou 板块结构分复刻）。

### H3 筹码质量甜蜜区（昨日量比 + 收盘位置组合）
- **假设**：昨日（涨停前一日）量比∈[0.55,2.2] 且收盘位置≥0.55 的票，封板率与次日胜率高于爆量(≥2.5)低收(<0.3)票；「爆量低收」是出货信号。
- **多角度论证**：
  - 机制：温和放量+收高=换手充分且买方主导；爆量低收=分歧中卖方胜出；
  - 反方：涨停股前一日常已放量拉升，量比分布右偏，甜蜜区可能样本少 → 报告各档样本量；
  - 对照：17_enriched 已有 y_vr/y_cpos，直接分档验证非线性。
- **因子**：`y_amt_ratio5`（昨日额/5日均额）、`y_cpos`（已有）、组合标签 `chip_flag`。

### H4 炸板疤痕（近20日触板未封次数）
- **假设**：近20日出现过「最高触及涨停价但未封住」的票，封板率与次日胜率更低——炸板疤痕代表上方套牢盘与封板资金的不信任（longtou 死亡测试的 broken_board 思想，且不可逆）。
- **多角度论证**：
  - 机制：炸板日高位接盘者成为压力位，再次冲板时抛压更重；
  - 反方：炸板也可能是「试盘/换手充分」，尤其炸板后缩量回踩再启动 → 区分「炸板后修复」与「炸板即追」；
  - 数据：daily_panel 用 high≥涨停价×0.999 且 close<涨停价×0.999 代理（涨停价=pre_close×板幅，近似口径，ST/20cm 需分类处理）。
- **因子**：`zb_cnt20`（近20日炸板次数）、`zb_recent5`（近5日）、`zb_repaired`（炸板后是否收复）。

### H5 板块内定价权（行业内相对地位）
- **假设**：决策前一日在所属行业内涨幅排名靠前（前3）且与第一名差距小的票，封板率与次日胜率更高——资金聚焦板块核心（longtou 龙头稀缺性门：rank≤3 通过、被替代且落后≥8分阻断）。
- **多角度论证**：
  - 机制：打板资金天然聚焦板块辨识度最高的票，跟风票封板质量差；
  - 反方：昨日本身涨停的票行业内排名天然靠前，与 y_zt 共线 → 需在非昨日涨停（扩容池/首板）子样本单独检验；
  - 对照：与现有五维评分的「题材热度」项正交（那是概念级，这是个股在板块内的相对地位）。
- **因子**：`ind_rank_prev`（昨日行业内涨幅排名）、`ind_gap_prev`（与行业第一涨幅差）。

### H6 连续负反馈（近端阴线压制）
- **假设**：近3日连续收跌（尤其≤-5%）的票封板率与次日胜率更低（longtou 连续负反馈≥2日阻断）。
- **多角度论证**：机制=短线资金记忆与止损盘；反方=超跌反抽涨停恰恰常见于连跌后 → 分档检验。
- **因子**：`neg_streak`（连续收跌天数）、`neg_deep`（近3日是否出现≤-5%）。

## 4. 验证计划（research/22_longtou_factors.py）

1. **数据**：17_enriched（决策时刻样本，封板率/当日/次日）+ events_enriched（2019-2026 长窗次日复核）+ daily_panel（因子计算）。
2. **前向验证**：17_enriched 自带 train/test 切分，阈值只允许在 train 定，test 只报结果；长窗 events 用 2019-2024 定阈值、2025-2026 复核。
3. **三段行情**：偏多/震荡/偏空分别报告（regime 列；events 用上证MA20口径补算）。
4. **主指标**：次日胜率；辅以封板率、当日胜率、盈亏比、五档单调性（Forward Return 分档）。
5. **时段效应**：按决策分钟 td（10:00 前/后）复核显著因子。
6. **通过标准**：test 段与 train 段方向一致、三段行情至少两段同向、五档近似单调、样本量各档≥100。

## 5. 验证结果摘要（详见 research/out/22_longtou_factors.md 与 23_combo_gate.md）

**最终落地成果（双窗前向单调）**：
1. **sscore 封板概率分**（炸板疤痕+行业涨停密度≥3%+行业排名前3+非爆量+高广度）：封板率 test 23.3%→60.2%（2.4x，train/test 双段单调）→ 封板率模型新特征组；
2. **qscore 次日质量分**（ldlr<0.5 + 行业排名>3 + 炸板≤1 + 量比甜蜜区）：次日胜率 test 72.7%→85.5%；长窗盈亏比 IS/OOS 均 1.26→1.62 单调 → 次日仓位分层（≤2 降仓）；
3. 连跌反抽 `neg_streak≥3`：次日胜率与盈亏比双升（长窗 IS 盈亏比 1.68 vs 1.47）→ 低拉队列加权。

**重要修正（研究23组合回测）**：ldlr_prev≥0.5 闸门在主力规则池上**无增量**（关闸日次日胜率反而≥73.7%，规则池盘中条件已内生过滤坏日）——不并入规则池闸门，改为广谱雷达预警层环境降权因子；主力规则池维持 research20 三闸门。

**最重要证伪**：longtou「龙头稀缺性」（板块内前3=优）在打板场景方向相反——前3票封板率高但次日胜率/盈亏比低（双窗一致），龙头稀缺适用二波持有，不适用打板次日兑现。

**其他证伪**：ld_prev 绝对家数（冰点反转）、cycle_prev/adv_prev（train/test 不一致）、行业广度（单调性不稳）、y_cpos（与 longtou 偏好相反，共线于 H5/H6）。

## 6. 研究24 融合与消融（假设→融合→消融闭环，详见 out/24_fusion_ablation.md）

把盘中动量组（r3/pathvol，研究17）、板块生态组（ind_ztdens/ind_rank/ind_breadth/zb_cnt20）、
筹码环境组（qscore 同源）做 rank 融合 + 组合模拟（top3 分仓、30% 成交、MC200）+ 消融：

- **正交性成立**（组间 |ρ|≤0.19），但**盘中动量与次日质量结构性负相关**（ρ=-0.19）——
  简单加权融合（H1）部分证伪：暴拉追高票封板率高但次日弹性差，目标冲突无法单分同时优化；
- **消融归因**：筹码组=次日质量主引擎（移除后次日胜率 79.9%→70.4%、Sharpe 8.47→7.67）；
  盘中组=封板率主引擎（移除后封板率 36.2%→29.5%）；生态组对已触板样本次日无增量（留在封板率模型）；
- **最终形态：两层架构（职责分离）**——结构层（g_chip/qscore）选"买谁"与仓位档位，
  盘中层（R2/P1）定"何时出手"；叠加早盘优先（≤10:00 次日胜率 82.4% vs 75.5%、盈亏比 3.09 vs 1.59）；
- **预期收益**（test top10%）：次日胜率 71.5%→79.9%（+8.4pp）、盈亏比 2.07→2.36、
  封板率基本持平（37.3%→36.2%）；三段行情无段内失效（84.4/78.6/77.0%）；
- 口径警示：Sharpe/年化绝对值因样本选择偏差虚高（V0 随机基线 Sharpe 11+），仅组间相对有效。

**研究24b 最终形态确认（六方案并行回测，组合级 top3/30%成交/MC200）**：
推荐 **V5 = 结构层过滤(g_chip≥0.6) + 融合分排序**。test 段对比现有方案近似 V1：
次日胜率 69.7%→74.6%（+4.9pp）、盈亏比 2.00→2.28（+14%）、Sharpe 7.75→9.24（+19%），
买入点胜率仅降 2.8pp（42.3%→39.5%）；train/test 双段同向、月度跑赢 3/4、三段行情无失效。
V6（纯结构排序）次日胜率 85.5%/Sharpe 11.11 最优但封板率降至 30.7%，不符合「先抓板」目标，仅供低吸队列。
落地：①扫板队列前置 g_chip≥0.6 结构闸；②触发维持盘中 R2/P1；③同分钟多触发按 V5 融合分降序分仓，早盘优先。

## 7. 落地实现（影子运行中，2026-08-27）

  v5_full（叠加 0.5×盘中 r3/pathvol 分位）；分位网格固化在 `data/meta/struct_grids.json`
