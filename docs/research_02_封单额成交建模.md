# 研究02: 封单额成交建模（2026-08-25）

核心问题: 能排进的板还赚不赚?（逆向选择量化）
样本: 88,543 可打板事件, fd_amount 零缺失

## 板型分类（成交场景划分）

| 板型 | 定义 | 占比 | T+1开盘收益 |
|---|---|---|---|
| 一封到底 | open_times=0 | 48.0% | +2.73% |
| 炸板回封 | open_times≥1 且 14:00前回封 | 30.7% | +2.27% |
| 尾盘回封 | open_times≥1 且 14:00后回封 | 21.2% | +0.13% |

尾盘回封切分点对13:30/14:00/14:30不敏感（早回封+2.0~2.5% vs 尾盘≈0 恒成立）。
**尾盘回封是垃圾样本（大热点内例外，+1.93%），策略必须排除。**

## 关键发现

**1. fd_ratio(封单额/成交额)是跨板型的通用质量因子，单调性极强**

一封到底内部五分位: Q1封单最薄 +1.28% → Q5最厚 +4.22%（日聚类t 16→63）
炸板回封内部五分位: Q1 -0.14% → Q5 +2.86%
→ 封单越厚=板越强=T+1越好，但一封到底板上封单越厚=排队越难成交（权衡曲线确认存在）

**2. 炸板次数单调衰减**: 炸1次 +2.23% → 炸2-3次 +1.52% → 炸4次+ +0.59%

**3. 题材集中度在可成交子集内依然单调**（逆向选择不破坏题材效应）:
炸板回封×孤板 +1.10% → ×大热点 +2.80%（日聚类t=15.9~27.7）

**4. 现实策略格（无前视，入场时点全部条件可知）**

定义: 大热点(独占涨停≥8家, 盘中可数) + 炸板后午前回封(回封确认时买入, 涨停价)
+ 炸板≤3次

| 指标 | 值 |
|---|---|
| n | 984 笔 / 6.8年 (约145笔/年, 0.6笔/交易日) |
| 单笔均值 | **+4.81%** |
| 中位数 | +4.44% |
| 日聚类t | 22.6, 覆盖339个交易日 |
| 逐年 | 2020 +5.90 / 2021 +4.27 / 2022 +4.83 / 2023 +3.44 / 2024 +5.58 / 2025 +4.20 / 2026 +3.87 —— 全正 |

叠加事后封单额过滤(收盘封单top40%, 有前视仅用于归因): n=743, +5.29%

**5. 逆向选择缺口在收窄**: (一封到底 − 回封板) 缺口 2019-2023 约1.8~2.2pp →
2024-25 约1.4pp → 2026 仅0.5pp（2026年回封板甚至反超一封到底）。
对实盘是好消息: 可成交样本的相对劣势在消失。

**6. 最强组合板型分解**: 大热点×早盘×龙头: 一封到底+7.59%(n=102) /
炸板回封+5.13%(n=153) / 尾盘回封-1.90%(n=18) —— 可成交部分依然+5%以上

## 局限与未建模风险

1. **炸板失败风险未入样**: 本表只含最终回封成功的事件(涨停池)。实盘在开板瞬间
   排单, 可能成交在最终未回封的板上(炸板股, 在limit_cpt_list)。本现实格的执行
   假设是"回封确认时买入"(规避失败风险, 代价是价格已到涨停位)——逻辑自洽,
   但回封确认的抢单竞争/滑点未建模。
2. 回封瞬间的排队竞争与成交时序需要分钟级数据验证(下一步)。
3. zt_cnt为收盘后独占归属口径, 盘中用涨停家数实时计数近似(略有出入)。
4. 2026年所有格的收益都在衰减(+3.87%仍为正), 与基准衰减一致, 持续监控。
