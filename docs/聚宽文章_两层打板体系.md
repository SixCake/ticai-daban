# 两层打板策略：结构选股 × 盘中择时（分钟级）

> 一套日内打板策略：盘前用昨日日线结构筛出"筹码健康"的候选池，盘中只在前一个小时捕捉触板信号触发买入，当天尾盘或次日兑现。本文说明策略的过滤、买入、卖出与风控四个环节的完整规则。

---

## 一、策略概览

| 环节 | 时点 | 动作 |
|---|---|---|
| 结构过滤 | 每日 09:05（盘前） | 全市场主板选股，4 项结构闸筛出候选池 |
| 买入 | 09:31 ~ 10:30 | 每分钟扫描触板信号，触发即市价买入 |
| 持仓监控 | 10:30 ~ 14:55 | 停止新买，只盯持仓止损 |
| 卖出 | 盘中 / 14:55 / 次日 | 回落止损、尾盘未封清仓、封板续持 |

**一句话逻辑**：只买"筹码结构干净"的票（无炸板疤痕、量比温和、非板块明牌龙头、或是超跌反抽），只在早盘信号质量最高的窗口出手，封不住就走、封住就拿。

---

## 二、过滤：候选池怎么来

### 第一层：基础池（09:05，只用截至昨日收盘的数据）

- 宇宙：中证全指成分中的**主板票**（600/601/603/605/000/001/002/003 开头，10% 涨跌幅）；
- 剔除：ST / *ST / 退市风险票；
- 剔除：上市不足 60 个交易日的次新股；
- 剔除：停牌、昨日无成交、日线数据不足 21 根的票。

### 第二层：结构闸（4 项中 ≥3 项健康才入池）

| # | 条件 | 含义 |
|---|---|---|
| ① | 昨日涨幅在所属行业内**排名非前 3** | 避开辨识度已被充分定价的板块明牌龙头 |
| ② | 近 20 日**炸板 ≤1 次** | 炸板=当日最高触及涨停价但收盘未封住；疤痕多的票次日抛压重 |
| ③ | 昨日量比 ∈ **(0.55, 2.2]** | 温和换手最优；爆量（≥2.5）视为出货迹象 |
| ④ | **连跌 ≥3 日** | 超跌反抽票，触板后次日修复行情质量高（加分项） |

4 项中满足 3 项即通过，入池率约 90%。这一步不预测涨停，只剔除"次日兑现质量差"的结构。

---

## 三、买入：什么时候扣扳机

### 触发窗口

**09:31 ~ 10:30**，每分钟全池扫描一次；10:30 后全天不再开新仓（早盘信号的次日质量显著优于午后）。

### 两类信号

**G 组（09:35 判定一次，高开票）**

开盘第一分钟涨幅 ≥1% 的票，取开盘 4 根分钟 bar：

- **稳封相**：当前涨幅 >5.2% 且 开盘后回撤 ≤0.05 个振幅点；
- **剧震**：当前涨幅 ≤5.2% 且 4 根 bar 振幅 >4.3%。

**L 组（每分钟，非高开票）**

- 现价**首次触及 昨收 × 1.01**（+1% 触板启动）；
- 且触发前 11 根分钟 bar 的轨迹波动（涨跌幅序列差分标准差）**>0.93** —— 颠簸式拉升换手充分，平滑拉升易诱多；
- 每只票的首触时刻只判定一次。

### 下单与仓位

- **触发即市价买入**（不挂低于现价的限价单，强势票不回踩，等回踩基本买不到）；
- 最多持 **3 仓**，每仓预算 = 总资产 / 3 与可用现金取小，按手取整；
- 同一分钟多个信号时，按**融合评分降序**依次买入直到满仓：

```
融合分 = 0.5 × 盘中强度 + 0.25 × 板块生态 + 0.25 × 筹码结构
盘中强度：L组=轨迹波动与3分钟涨速归一均值；G组=开盘振幅归一
```

- 已涨停封死 / 停牌等买不进的情形由撮合自然拒绝，不重复尝试。

---

## 四、卖出：三种出场路径

### ① 回落止损（盘中，每分钟检查）

- 参考价 = max(买入价, 当日持仓期间最高价)；
- 现价从参考价**回落 5%** 立即市价清仓。

### ② 尾盘判定（14:55）

- **未封板** → 清仓（当日逻辑未兑现，不留过夜不确定性）；
- **封板**（现价 ≥ 涨停价 × 0.995）→ **续持至次日**，次日 14:55 再判：仍封板继续续持，不封则清。

### ③ 次日处理

昨日买入的票今日 14:55 前享受回落止损保护，尾盘按 ② 重新判定。

---

## 五、风控要点

| 风控项 | 规则 | 目的 |
|---|---|---|
| 时间窗口 | 10:30 后停止买入 | 午后信号质量低，且规避尾盘诱多 |
| 分仓上限 | 最多 3 仓 × 1/3 资产 | 分散单票跳空肥尾冲击 |
| 结构闸前置 | 疤痕/爆量/明牌龙头不入池 | 从源头砍掉次日大亏尾部 |
| 回落止损 | 参考价回落 5% 无条件走 | 单笔最大亏损可控 |
| 不封即走 | 14:55 未封清仓 | 打板的逻辑就是封板，不兑现不恋战 |
| 成交假设 | 回测按 30% 买入成交概率抽样 | 模拟涨停板排队买不进的真实难度，避免回测虚高 |

## 六、参数一览

| 参数 | 值 | 说明 |
|---|---|---|
| 结构闸通过线 | 4 项 ≥3 项 | 入池门槛 |
| 炸板窗口 | 近 20 日 | 触板未封计数 |
| 量比甜蜜区 | (0.55, 2.2] | 昨日量 / 前 5 日均量 |
| 触板线 | 昨收 +1% | L 组触发 |
| 轨迹波动阈值 | 0.93 | 11 根 1m bar 差分标准差 |
| 高开线 | +1%（首分钟） | G 组入围 |
| 稳封相 | 涨幅 >5.2% 且回撤 ≤0.05 | G 组形态一 |
| 剧震 | 4bar 振幅 >4.3% | G 组形态二 |
| 买入窗口 | 09:31 ~ 10:30 | 每分钟扫描 |
| 回落止损 | 5% | 参考价 = max(买入, 日高) |
| 尾盘判定 | 14:55 | 封板价 ×0.995 |
| 最大持仓 | 3 仓 × 1/3 | 等权分仓 |
| 回测成交概率 | 30% | 涨停买入难度模拟 |

---

## 七、使用说明

- 回测建议：分钟频率，初始资金 100 万，基准上证指数；
- 策略对数据的要求：候选票 22 根日 bar（结构因子）+ 当日 1 分钟 bar（触发判定）；
- 关键行为核对：日终日志输出 候选数 / 闸通过数 / 信号数 / 成交数 / 持仓明细，可逐日归因。
