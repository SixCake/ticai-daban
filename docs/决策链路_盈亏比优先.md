## 0. 目标函数与两条铁律杠杆

盈亏比 = 平均盈利 / |平均亏损|。要提高盈亏比，只有两条路（全局铁律）：

- **放大盈利单**（让赚钱的单子更大）：封板续持抓次日溢价、抓高度连板、E3 强封单筛选续持
- **压缩亏损单**（让亏钱的单子更小）：低位入场、止损不误杀、分时弱势提前卖

> 提高胜率是第三杠杆（用户定：盈亏比优先，胜率次要）。胜率靠题材/竞价信号，
> 但**盈亏比靠价位与离场结构**——这是本链路的重心。

### 0.1 量化目标：盈亏比 **3 以上**（用户 2026-09-09 定）

当前 → 目标差距：

| 口径 | 盈亏比 | 状态 |
|---|---|---|
| 全体 baseline | 0.99 | 起点 |
| P0-a 入场价位闸 pct≤4% | 1.34 | 已落地 |
| 封板续持(全部) | 2.44 | 已落地 |
| **E3 高档封板续持** | **3.19** | 唯一达标口径(研究50) |

**关键洞察**：盈亏比 3+ **只在「E3 高档封板续持」子集达到**(研究50 3.19)。
全体混合(封板8% + 不封板92%)永远到不了 3 —— 不封板票盈亏比 0.67 会拉低。
→ 要整体盈亏比 3+, 策略必须**聚焦到「高封板命中率 + E3高续持」极窄子集**,
牺牲交易频率换盈亏比 —— 这是打板「少而精」的本质。

**3+ 路径 = 三重聚焦**：
① 买入前: 低位(pct≤4%) + 强题材(T3) → 提高封板命中率(研究35 T3封板率25.3%)
② 买入后: 封板确认 → 续持
③ 续持筛选: E3 高的续持(盈亏比3.19), E3 低的次日开盘卖

## 1. 盈亏比数据基线（现状诊断，优化的起点）

| 口径 | 盈亏比 | 期望 | 来源 |
|---|---|---|---|
| 全宇宙打板（各入场档） | **0.77~0.84** | −2.5%~−4.1% | 研究40 |
| 封板票 · 次日开盘离场 | 2.65 | +5.87 | 研究36 G2 |

提盈亏比 = ①让更多票进入"封板续持"正收益区（放大盈利单）②低位入场+止损优化压缩亏损单。

## 2. 决策链路全局架构（5 环节流水线）

```
【盘前 T-1】题材锁定 + 结构闸
    ↓  选出"今天会强"的题材 + 筹码健康的票
【竞价 09:25】竞价×价位二维闸 + 观察名单
    ↓  低位埋伏候选（竞价放量但价格未启动）
【盘中买入 09:30–10:30】入场价位闸门 + 早盘时段
    ↓  只在 2~4% 可行区低位买，不追高
【持仓管理】分时弱势 + 波动自适应止损
    ↓  真弱势才卖，洗盘波动不误杀
【卖出/续持】封板后 E3 强度观测 + P2 + 封板续持
       放大盈利单：强封单续持抓次日溢价
```

### 环节1 · 盘前题材锁定 + 结构闸
- **现状**：结构闸 `g_chip` 已落地（[`strategy.py`](../strategies/v5_daban/strategy.py) before_trading）；T 级信号只作观察，未接买入闸（[`core/theme_signal.py`](../core/theme_signal.py)）
- **数据**：研究42 题材天梯滚动热度（近3日累计预测次日在场 64.3% vs 现行 59.6%）；研究35 T3 封板率 25.3% > 打平线 21.2%
- **待验证**：T 级能否作买入闸（需三段验证）；天梯排序键改滚动热度
- **对盈亏比**：强题材 → 封板续持概率高 → **放大盈利单**（间接）

### 环节2 · 竞价×价位二维闸
- **现状**：竞价闸只作观察名单密度过滤（研究31 定稿，[`core/early_signal.py`](../core/early_signal.py)）
- **数据**：研究31 竞价量比提高封板率（12.41% vs 1.00%）但次日胜率反向（37.9%<39.5%）——**根因：域写死 `gap≥1%`（已高开），筛出的是"高位高封板率"，EV 最差**
- **待验证（研究49）**：竞价量比 × 入场价位(gap) 二维交叉，找 **"低 gap + 高 vr"（竞价放量但价格未启动）** 黄金子集，看能否封板率越打平线且价位在可行区
- **对盈亏比**：低位埋伏 → **压缩亏损单**（直接）

### 环节3 · 盘中买入入场价位闸门 ★核心地基
- **现状**：`strategy.py` **无 pct 闸门**（缺口）；10:30 后不买已落地
- **数据**：研究08 机制矩阵——2~4% 可行 / 4~6% 边际 / 6%+ 数学不可行；低位入场亏损单小（8~12% 未封板票 EV −10.72%）；研究07 早盘封板率 11% vs 午后 ≤1%
- **待验证**：`pct≤4~6%` 硬闸的三段回测（多档阈值并行）
- **对盈亏比**：**核心地基**！低位入场 = 亏损单小 = 盈亏比高（直接，最强）

### 环节4 · 持仓管理 分时弱势 + 波动自适应止损
- **现状**：固定 5% 止损已落地；分时弱势未落地
- **数据**：研究36 I1 止损盈亏比 0.32、期望 −3.80；研究47 触发后 5min MA5偏离/RSI 强区分度（8日稳定）；研究48 分时弱势提前卖
- **待验证（研究46，第一优先）**：**止损反事实**——止损离场 vs 不止损持到收盘，`diff<0` 才证明误杀，再谈波动自适应
- **对盈亏比**：**压缩亏损单**（不误杀）（直接）

### 环节5 · 卖出/续持 封板后 E3 强度 + P2 + 封板续持 ★核心杠杆
- **现状**：`strategy.py` 用 14:55 清仓（与 [`exit_rules.py`](../core/exit_rules.py) 的 P2 10:10 **口径分叉**）；封板续持已落地；E3 未接入
- **数据**：研究41 E3 封单超预期 **+23.9pct**（三段同向，全项目最强单因子，封板后可观测）；封板续持期望 +11.10 盈亏比极高；研究06 封板组内"硬封不炸"可预测
- **待验证**：E3 接入续持判据（[`clear_unsealed`](../strategies/v5_daban/strategy.py)）；P2 口径对齐；封板续持抓高度
- **对盈亏比**：**核心杠杆**！放大盈利单（封板续持 +11.10）（直接，最强）

## 5. 落地纪律（项目铁律，不可违背）

1. **影子先行**：新维度先只进影子字段 + 看板展示，不接买卖闸
2. **三段验证**：任何方案写进 core 前必须过牛/熊/震荡三段，同向 ≥2/3
3. **显著性校正**：多组合择优必须做 Bonferroni，避免 p-hacking（研究43 教训）
4. **多方案并行**：提优化方向必须设计多候选并行回测，数据择优
5. **白盒可解释**：只用可人工复现的因子，拒绝黑盒
6. **口径唯一出处**：离场用 `core/exit_rules`，因子用 `core/shape`，避免分叉

### 2026-09-09 · 整体盈亏比3 的数学路径验证（关键转向）
- **止损改造验证**：不止损把整体盈亏比 0.82→1.07（平均盈利+1.55→+2.27, 平均亏损-1.90→-2.11）—— 离3远
- **数学现实**：整体盈亏比3 无法靠「全体混合」实现 —— 86%不封板票把平均亏损锚在-2, 平均盈利最多+2.27, 盈亏比≤1.07
- **关键转向：瓶颈在买入端不在卖出端**。E3续持只提高封板子集盈亏比(3.19), **不改变整体**(整体仍含不封板亏损); 整体盈亏比由**封板率**决定 —— 封板率越高整体越接近封板票的3.19
- **整体3的唯一路径**：买入端把封板命中率拉高(研究36「昨日首板+T3」封板率66.7%) + E3高续持。两者缺一不可
- **下一步**：P2-b 验证买入端高封板命中率方案(T3+首板)的整体盈亏比能否达3

### 2026-09-09 · 决定性结论：策略整体盈亏比3+ 数学上不可达
- **T级验证推翻上一轮假设**：T3封板率32.4%(最高)但盈亏比0.68(最低); T1封板率11.2%盈亏比0.96(最高) → **封板率与盈亏比负相关**，「提高封板命中率→整体3」是错的(印证研究08/31「封板率与EV反向」)
- **组合验证(研究51)**：低位(pct<4)样本 10154，其中「封板且E3≥0.20续持」仅 104 条(**占比1.02%**)。E3高续持盈亏比3.19，但占比1%无法拉动整体，整体盈亏比≈1.35
- **最终判断**：打板「买入等封板」模式下 **策略整体盈亏比3+ 数学上不可达** —— 买入票大部分不封板(亏损单锚定平均亏损)，唯一达标的E3高续持只是1%封板子集，不代表整体
- **可达的3+**：封板续持**盈利引擎**(E3≥0.20子集)盈亏比3.19已达标 → 落地E3续持闸让「封板续持」这一盈利来源达3.19
- **下一步**：落地E3续持闸到 clear_unsealed(封板资金数据链路)

### 2026-09-09 · 重大突破：E3高封板续持盈亏比 **3.74** 达标(历史大样本)
- **验证(研究51延伸)**：昨日 E3≥0.20 封板票次日开盘卖，**38701 样本**(跨2019-2026)，胜率80.1%，**盈亏比 3.74**，期望+4.37 → **盈亏比3+目标达标**

### 2026-09-09 · 闭环验证：次日接力模式不可行，整体3+彻底不可达
- **次日接力验证**：昨日封板E3高票，次日开盘买入→次日收盘卖，**38772样本**，胜率33.8%，**盈亏比仅1.18，期望-0.90** → 不可行
- **根因**：3.74盈利来自「隔夜溢价」(昨日涨停价→次日开盘)，**只能由昨日打板持有获得**；次日接力买入时隔夜溢价已被开盘价吸收，日内反而亏
- **最终闭环结论**：打板盈亏比3+ **数学上彻底不可达** —— 3.74盈利必须昨日打板持有(含不封板亏损→整体~1.35)，无法通过任何可执行模式剥离亏损单达到整体3
- **已达成的**：盈利引擎盈亏比3.74(E3续持闸已落地) + 整体从0.99提至1.34(入场价位闸)
