## 一、方法论框架（五步闭环）

研判不是「猜涨幅」，而是**用已落库数据做证据链交叉验证**，输出带条件的观察名单。

| 步骤 | 做什么 | 关键纪律 |
|---|---|---|
| **1 数据核验** | 确认真实最新交易日、区分盘中/收盘、核对各源时间戳 | 不以文件修改日期冒充数据日期；盘中截面 ≠ 收盘定稿；剔除未来时点/日期错位条目 |
| **2 板块强弱** | 市场宽度（上涨家数占比）、申万一级等权涨幅、题材热度 + T 级 + 波次/持续性 | 方向差 = 上涨股成交额 − 下跌股成交额，**不是主力净流入**；近板 ≠ 封死 |
| **3 催化交叉验证** | AI 线索 / 财联社原文 / 题材智能体报告，核验时间、来源、正负影响、置信度 | 报道 ≠ 公司公告核实；区分「催化已传导为涨停」与「催化待传导」；禁用 radar 热度事后追认 |
| **4 个股筛选** | 主线板块内选龙头：封板一致性（开板次数）、封单额、首封时间、连板高度、T/S 级 | 一致封板 + 早封 + 大封单 > 分歧/尾盘板；3 板以上属高位接力风险区 |
| **5 风控底线** | T+1 约束、板块集中度、隔夜溢价兑现节奏 | 关注名单 ≠ 可成交买点；大幅高开且承接不足则不追 |

**T 级口径**（core/theme_signal.py，数字越大越强）：T3 = 封板≥2 且昨日最高板≥2（最优）；T2 = 封板≥1 且昨日有活跃题材；T1 = 无确认/龙一负反馈（最弱）。锚定昨日天梯，不含未来信息，仅作观察排序、不作买入闸。

## 四、可复用清单

**盘前必查**：
1. 最新交易日 & 盘中/收盘口径；各源时间戳；剔除日期错位条目。
2. 市场宽度（上涨家数占比）→ 判断是全面回暖还是局部抱团。
3. 申万一级等权涨幅前 6 + 题材热度前 6（T 级、波次、持续性）。
4. 催化置信度（可确认/中/低）+ 是否已传导为涨停（区分待传导主线）。
5. 涨停池：连板梯队 + 一致封板（开板 0 次）+ 封单额 + 首封时间。

**风控底线**：
- T+1：当日买错不能当日止损；隔夜溢价策略以开盘兑现为主。
- 集中度：同一产业链（如 PCB/覆铜板/电子布同属电子材料链）不算独立分散。
- 3 板以上 = 高位接力风险区，只观察有承接的换手，不追一字/失控高开。
- 关注名单 ≠ 买点：大幅高开且板块扩散/换手承接不足则放弃。
