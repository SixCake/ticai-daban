# 题材复盘方法论：三层结合复盘法

> 本文档沉淀"参考级题材复盘"的方法论。核心结论：**纯行情数据反推无法产出
> 完整复盘**——参考级复盘 = 行情数据 + 外部催化检索 + 人工/LLM 深度分析三层结合。

## 一、为什么纯数据反推质量低

题材复盘的完整信息有三类来源，**只有第一类能从项目行情数据反推**：

| 信息支柱 | 来源 | 能否纯数据反推 |
|---|---|---|
| ① 行情量价 | daily_panel + kpl_members | ✅ 能（自动化）|
| ② 催化事件/叙事 | 外部新闻（财联社/雪球/财新/格隆汇）| ❌ 不能（需检索）|
| ③ 产业链+四维穿透 | 人工标注（主营业务/壁垒/兑现/格局/天花板）| ❌ 不能（需人工/LLM）|

**逐日还原表的"当日事件/叙事"**（如"美光闪迪宣布 NAND 提价超 10%"）是人工
从外部新闻检索填写的，不是从 K 线反推的。催化事件、产业逻辑、四维基本面
**无法从行情数据反推**——这是方法论的根本边界。

## 二、三层结合复盘法

### 数据层（项目自动化，脚本计算）
- **纯度溢价**：核心股等权篮子 vs 全池等权篮子涨幅差（选股权重 > 仓位权重）
- **篮子净值**：核心股 + 全池归一化净值曲线（中位净值抗单只大牛股）
- **涨停梯队**：kpl_events 逐日涨停集群 + 连板高度（limit_times）
- **阶段轴**：趋势型用篮子中位净值拐点；情绪型用涨停家数滚动窗口
- **各阶段涨幅**：角色队列每只股在潜伏/启动/发酵/高潮/二波的涨幅

### 催化层（外部检索，WebSearch/WebFetch）
- **第一催化**：题材启动的催化事件（公司公告/政策/价格信号），标置信度
- **当日事件/叙事**：逐日还原表的事件列（区分因/果），来自财联社/雪球/财新
- **信源**：每条催化信息的出处引用（可追溯）

### 深度层（人工/LLM，config 填写）
- **核心驱动链**：产业逻辑链条（每环可独立验证）
- **产业链拆解**：环节（原厂/设计/模组/分销/封测/设备/材料）+ 受益弹性排序
- **四维穿透**：核心壁垒 / 业绩兑现周期 / 竞争格局 / 天花板
- **角色判定**：一波龙头/二波龙头/中军/补涨/影子股
- **操作要点/证伪条款/偏差记录**

## 三、复盘工作簿标准结构（10 sheet）

| sheet | 内容 | 数据来源层 |
|---|---|---|
| 1 题材档案卡 | 分类/父题材/池/第一催化/驱动链/产业链/生命周期/全程表现/结局/可复制性/证伪 | 深度+催化+数据 |
| 2 全成分股池 | 全池涨幅排序 + 角色初筛 | 数据 |
| 3 角色队列 | 核心股四维穿透 + 各阶段涨幅 | 深度+数据 |
| 4 逐日还原表 | 篮子涨跌/领涨股/当日事件/叙事/阶段 | 数据+催化 |
| 5 阶段统计 | 阶段划分/标志事件/资金行为/操作要点/退潮信号 | 数据+深度 |
| 6 剧本提炼 | 驱动结构/发酵路径/角色规律/纯度溢价/同构题材/可复制性/响应链/证伪/偏差 | 深度 |
| 7 行情数据 | 核心股日行情 + 篮子 | 数据 |
| 8 全池行情 | 全池归一化 + 等权篮子 | 数据 |
| 9 空白模板 | 填写规范 | 规范 |
| 10 信源 | 数据来源引用 | 催化 |

## 四、执行流程

```
1. 定题材+窗口+股票池(kpl curated 成分, 剔 .BJ/ST)
2. 数据层: 脚本自动算 篮子/涨停梯队/阶段轴/纯度溢价/各阶段涨幅
3. 催化层: WebSearch 检索第一催化+逐日事件(财联社/雪球/财新), 标信源
4. 深度层: 人工/LLM 填 config(驱动链/产业链/四维穿透/角色/证伪)
5. 脚本合成多 sheet 工作簿(xlsx), 数据层字段公式联动行情
6. 对比参考质量, 记录偏差
```

## 五、关键纪律（避免历史教训）

1. **股票池用 kpl curated 成分**（kpl_theme_pool），不用事件级直标（污染）。
2. **趋势型阶段轴用篮子中位净值**，不用涨停数（机构趋势行情涨停数低会误判）。
3. **窗口取全生命周期**，不照抄外部转录（避免截断最大一腿）。
4. **角色按峰值时序 + 强度分位**，不用全程涨幅分位（前视）。
5. **催化事件标信源 + 置信度**，转录数字须核实（不照抄未核实外部结论）。
6. **纯度溢价须算核心 vs 全池**，揭示选股权重。
