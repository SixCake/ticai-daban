# 研究05: 涨停概率v0复盘与校准方向（2026-08-25）

核心问题: 盘中概率榜的分数到底可信不可信? 哪些项该留/该改/该补?
样本: radar_log_20260825 12.7万分钟行 + radar_labeled_20260825 1533 stock-day（涨停65, 收盘最终版）
方法: 三个快照时点（首次pct≥4 / 首次pct≥7 / 概率峰值）单变量AUC + numpy逻辑回归（标准化系数）

## 1. 排名能力成立, 校准不成立

v0 prob AUC: 首次≥4%快照 0.950, 首次≥7%快照 0.923; 召回 65/65=100%（涨停股prob_max最低0.98）。
但收盘最终校准桶:

| prob_max | 10cm实际涨停率 | 20cm实际涨停率 |
|---|---|---|
| ≥90% | **90%** (68只) | **19%** (21只) |
| 70-90% | 0% (11) | 0% (8) |
| 50-70% | 0% (18) | 0% (3) |
| 30-50% | 0% (17) | 0% (5) |

结论: ①10cm≥90%段诚实, 可直接信; ②20cm≥90%严重过自信（+15%以上被0.55×涨幅项推到95-99%, 量比2.1与10.8同分）; ③中段30-90%全桶0涨停, 分数二元化="没近板", 幅度无概率含义。

## 2. v0逐项审计（数据裁决）

| 项 | v0设定 | 裁决 |
|---|---|---|
| +0.55×涨幅 | 正 | 方向对(AUC .81-.92), 但20cm饱和, 需板型缩放/封顶 |
| -0.30×距板 | 负, 权重弱 | 方向对且是主导因子(-dist AUC .94-.99); 权重太弱→10cm距板0.6%(64%)排在20cm+16%距板3%(99%)后面, 倒挂 |
| +0.5×涨速3m | 正 | **被数据反对**: 全部快照AUC 0.21-0.27反向（赢家记录时点已封=速0, 输家高位震荡=速高）; 含1分钟日志频率伪影, 降级触发项, 20s日志重验 |
| +0.35×量比 | 正 | **确认** AUC 0.60-0.82正; 保留可加权 |
| +0.08×min(heat,15) | 正, 饱和 | 替换为trank: 赢家峰值trank 2.1/早期0.2-1.2 vs 输家8.5-16.4（AUC .29-.41反向=越小越好）, 主线效应强 |
| tover（缺失） | — | **强因子反向**: 赢家换手0.4-1.1 vs 输家1.7-2.8 (AUC .33); 20cm触板时刻 封住=0.00 vs 没封=5.73 (AUC .29) → 封板意愿因子, 负号纳入 |
| dheat（候选正） | 日志待验 | **反向** 0.42-0.45: 个股层面"题材正升温"=追高, 赢家dheat 0.03-0.10 vs 输家0.28-0.70; 负号或剔除 |

逻辑回归（首次≥7%快照, 标准化系数）: dist -4.31 主导, dheat -0.71, s3 -0.39, trank -0.36, vr -0.22, tover +0.23（与单变量反号=与dist共线, 204样本不稳, 不解读符号）, b20 +0.05。
拟合AUC 0.946 vs v0 0.923: 排序提升小, 价值在**校准与符号修正**, 不在排名。

## 3. 预警领先性是真正短板

lead50≥0 仅 12/65（中位28.4min）; 首封前5分钟内 prob≥80% 可见仅 7/65。
根因: 公式本质是"距板接近度探测器"而非"起 ramp 预测器"——赢家在两条1分钟日志之间完成拉升（首次≥4%记录时赢家均值涨幅已达9.04%、dist 1.5%, AUC(dist)=0.044反向）。
对策: ①日志改每cycle(20s)全量记录, 保留真实ramp轨迹（已于当日实施）; ②研究06用20s轨迹研究ramp前动量/点火因子。

## 4. v1方案（冻结, 待多样本OOS验证）

分板型(10cm/20cm)分别校准; dist主导加权; +vr; -tover; -trank(或rank形式热度); 涨速降级; dheat负号或剔除; 20cm触板候选叠加封板意愿(tover/vr)。
**单日=in-sample, 禁止直接上线**（项目纪律）; 积累3-5天20s日志后 out-of-sample 验证再替换v0。
